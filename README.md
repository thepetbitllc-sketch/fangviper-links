# Fang Viper Links

Link-in-bio page for Fang Viper: the store, the journal and every social channel. Plain HTML, hosted free on GitHub Pages.

Live site: https://links.fangviper.com/

## Editing

- Everything lives in `index.html`. Each link is one `<li>` block: copy a block to add a link, delete it to remove one, move it to reorder.
- `assets/og.png` is the preview image shown when the link is pasted into a chat or post.
- Brand icons are from [Simple Icons](https://simpleicons.org) (CC0).
